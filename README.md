# Krl-sta Tap

## How do I install these formulae?

`brew install krl-sta/tap/<formula>`

Or `brew tap krl-sta/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "krl-sta/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
